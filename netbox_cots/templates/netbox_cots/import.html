Importer un CSV

En-tête minimal : role,cots,version. Le rôle est identifié par son slug exact. Colonnes optionnelles : role_id,cots_slug,publisher,tags. Encodage UTF-8 ; séparateur virgule ou point-virgule. Les tags de l’affectation sont séparés par | ; les tags existants sont conservés.
